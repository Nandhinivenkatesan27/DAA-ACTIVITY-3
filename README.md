Activity 3 – Java

Description

This repository contains Java solutions for five LeetCode problems. It focuses on implementing Data Structures and Algorithms (DSA) to improve coding efficiency, logical thinking, and problem-solving skills.

Problems Covered

1. Sort an Array (912) – Merge Sort
2. Top K Frequent Elements (347) – HashMap and Priority Queue
3. Find Median from Data Stream (295) – Two Heaps
4. Course Schedule (207) – BFS and Topological Sorting
5. Merge Intervals (56) – Sorting and Interval Merging

Objectives

- Understand and implement essential DSA concepts.
- Develop efficient solutions to algorithmic problems.
- Improve logical thinking and Java programming skills.
- Learn to analyze algorithm performance.

Language and Concepts

- Language: Java
- Concepts: Arrays, Sorting, HashMap, Heaps, Priority Queue, Graphs, BFS, and Interval Merging.

Conclusion

This activity strengthened my understanding of Data Structures and Algorithms and improved my Java coding and problem-solving skills through practical implementation.
